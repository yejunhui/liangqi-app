Liangqi — это **локальное веб-приложение для совместного учёта**, которое разделяет расходы наличными и покупки в кредит:

- **Расходы наличными** сразу вычитаются из сбережений.
- **Покупки в кредит** не трогают сбережения: они увеличивают обязательства и признаются расходом при погашении.
- **Погашение** переводит деньги из активов в обязательства и фиксирует расход в этот период.

По умолчанию данные хранятся в браузере. Можно вести несколько книг и подключить репозиторий GitHub, Gitee или WebDAV, чтобы делиться одной книгой с несколькими людьми.

## Как это работает

| Действие | Активы / сбережения | Обязательства | Расход |
| --- | ---: | ---: | ---: |
| Покупка за наличные | −100 | 0 | +100 |
| Покупка в кредит | 0 | +100 | 0 |
| Погашение | −100 | −100 | +100 |
| Получен кредит | +100 | +100 | 0 |

- Покупка в кредит только увеличивает обязательства; **при покупке расход не создаётся**.
- При погашении уплаченная сумма признаётся расходом.
- Чистый капитал = активы − обязательства. Покупка в кредит уменьшает его из-за роста обязательств; погашение его не меняет.

## Возможности

- **Несколько книг**: семья, путешествия, бизнес и другие, с быстрым переключением.
- **Активные и пассивные счета**: наличные, банк, кредитная карта, Huabei, займы и начальные остатки.
- **Счета к оплате**: название, категория, срок, частичное погашение, статус.
- **Погашения**: с активного счёта; обязательства и сбережения уменьшаются одновременно.
- **Участники**: привязка счетов и операций к членам семьи; общие книги с входом по участнику.
- **Теги и двухуровневые категории**: контекст, назначение, человек; родительские и дочерние категории.
- **Бюджеты и регулярные операции**: месячные или годовые, по категории, тегу или участнику.
- **Импорт CSV**: WeChat, Alipay и банки с автоматическим определением столбцов.
- **Мультивалютность и вложения**: курсы, исходная сумма и файлы до 10 МБ.
- **Аналитика и отчёты**: динамика, категории, теги, участники, тренд за 6 месяцев, CSV и PDF.
- **AI-ассистент**: с API, совместимым с OpenAI, анализирует книгу и предлагает бюджеты.
- **PWA и офлайн**: установка на компьютер или телефон, офлайн-открытие интерфейса.
- **10 языков**: китайский (упрощённый и традиционный), английский, японский, корейский, испанский, французский, немецкий, португальский и русский.

## Быстрый старт

Используйте онлайн-версию или запустите локально:

```bash
pnpm install
pnpm dev
```

Сборка:

```bash
pnpm build:workbook
```

Подробное руководство по развёртыванию: [docs/deployment.md](docs/deployment.md) (на китайском).

## Данные и конфиденциальность

- Книга хранится в **IndexedDB** браузера, `localStorage` используется как резерв.
- При подключении удалённого репозитория данные находятся в вашем GitHub / Gitee или WebDAV. У Liangqi нет собственного сервера данных.
- Пароли участников хранятся только как **хэш PBKDF2**, без открытого текста.
- Токены и ключи AI API остаются в `localStorage` устройства и не проходят через серверы Liangqi.
- Очистка данных браузера удалит локальную книгу. Регулярно экспортируйте резервные копии.
