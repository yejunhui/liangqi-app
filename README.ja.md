# Liangqi · 両訖

> 銀貨両訖、帳簿も両清。

Liangqi は、**現金支出とクレジット購入を分けて管理するローカルファーストの共有家計簿 Web アプリ**です。

- **現金支出**は、その場で貯金から差し引きます。
- **クレジット購入**は貯金を減らさず、負債だけを増やします。返済時に支出として計上します。
- 返済は「資産 → 負債」の移動で、返済した期の支出になります。

データは通常ブラウザ内に保存されます。複数の帳簿を作成でき、GitHub / Gitee / WebDAV のリポジトリに接続すると、1 つのリポジトリを複数メンバーで共有できます。

## しくみ

| 操作 | 資産 / 貯金 | 負債 | 支出 |
| --- | ---: | ---: | ---: |
| 現金購入 | −100 | 0 | +100 |
| クレジット購入 | 0 | +100 | 0 |
| 返済 | −100 | −100 | +100 |
| 借入金の入金 | +100 | +100 | 0 |

- クレジット購入は負債だけを増やし、**購入時点では支出にしません**。
- 返済時に、返済額を支出として認識します。
- 純資産 = 総資産 − 総負債。クレジット購入でも負債が増えるため純資産は下がりますが、返済では変わりません。

## 主な機能

- **複数帳簿**：家族・旅行・事業などの帳簿を 1 つのライブラリで管理。
- **資産 / 負債口座**：現金、銀行口座、クレジットカード、花唄、借入など。期首残高に対応。
- **請求管理**：請求名、カテゴリ、期限、一部返済、完済状態。
- **返済**：資産口座から返済し、負債と貯金を同時に減らして支出を計上。
- **メンバー**：請求や取引を家族メンバーに紐付け。共有帳簿ではメンバーごとにログイン。
- **タグ / 2 階層カテゴリ**：生活シーン、用途、対象などのタグと、親子カテゴリ。
- **予算 / 定期記帳**：月次・年次予算、カテゴリ / タグ / メンバー別の予算、定期取引。
- **CSV インポート**：WeChat、Alipay、銀行の CSV を列自動判定で取り込み。
- **多通貨 / 添付ファイル**：外貨建て取引と為替レート、レシートや請求書の添付（最大 10 MB）。
- **分析 / レポート**：資産推移、カテゴリ別、タグ別、メンバー別、6 か月トレンド、CSV / PDF 出力。
- **AI アシスタント**：OpenAI 互換 API を設定すると、帳簿に基づく分析や予算提案が可能。
- **PWA / オフライン**：ホーム画面にインストールでき、アプリシェルをオフラインで開けます。
- **10 言語**：簡体字中国語、繁体字中国語、英語、日本語、韓国語、スペイン語、フランス語、ドイツ語、ポルトガル語、ロシア語。

## データとプライバシー

- 帳簿はブラウザの **IndexedDB** に保存され、`localStorage` が予備になります。
- リモート接続時は、自分の GitHub / Gitee リポジトリまたは WebDAV に保存されます。Liangqi のデータサーバーはありません。
- メンバーのパスワードは **PBKDF2 ハッシュ**のみを保存し、平文は保存しません。
- トークンと AI API キーは端末の `localStorage` に保存され、Liangqi のサーバーを経由しません。
- ブラウザデータを消すとローカル帳簿も消えます。定期的にバックアップを書き出してください。
